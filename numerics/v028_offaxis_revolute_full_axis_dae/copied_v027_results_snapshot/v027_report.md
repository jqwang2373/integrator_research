# v027 Experiment Report

Generated by `run_v027.py`.

## Purpose

- Test a stronger square residual for v023/v026's absolute-coordinate quaternion revolute DAE.
- The `*_pivotva` methods replace stage `r` collocation with the pivot velocity constraint and replace stage `v` collocation with the pivot acceleration constraint.
- Keep raw Gauss4/Gauss6, v026 `*_pivotvc`, and the projected Gauss6 repair as baselines.
- Keep Brown-McPhee friction dependent on the stage reaction-force norm so JAX differentiates the coupled friction/multiplier residual.
- Endpoint velocity and stage velocity/acceleration constraint parts are reported separately.

## Interpretation

- PivotVA is a stricter in-residual consistency test than v026 PivotVC, because it adds pivot acceleration while keeping the Newton system square.
- If PivotVA improves drift without increasing trajectory error, it is the better full-DAE repair; if it fails or worsens accuracy, v026 PivotVC remains the more pragmatic in-residual repair.
- The test still covers only the pivot acceleration part of this one-DOF revolute joint; full lower-pair acceleration consistency for general joints remains open.
- Projected Gauss6 remains the strict endpoint-closure baseline, but projection changes the endpoint state after the collocation solve.
