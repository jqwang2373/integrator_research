# agentic_research — the process paper

**"Agentic auto-research in numerical analysis: a coding agent finds, proves and validates a
sixth-order Lie-group integrator."** A case study of how the Gauss6/FullVA program in this
repository was carried out by a coding agent under human direction: the process architecture
(versioned tree, evidence ledger, proof sandbox, memory, command boundaries, manuscript
pipeline), the trajectory through the 49 versions, ten incidents in which a wrong claim was
caught and by what, and a quantitative account of the final session. NeurIPS 2025 style
(`preprint` option), nine pages of main text plus references and appendices.

| File | What it is |
| --- | --- |
| `main.tex` | Preamble, title, abstract; inputs `sections/01_intro … 09_conclusion` and `sections/appendix`. |
| `sections/*.tex` | The paper, one file per section. |
| `references.bib`, `neurips_2025.sty` | Bibliography (natbib/plainnat) and the official style file. |
| `make_figures.py` | Draws `figures/fig_versions.png` (from `../../numerics/v0*`), `figures/fig_session.png` (from the Claude Code transcript under `~/.claude/projects/`), `figures/fig_pipeline.png` (schematic); writes `stats.tex`, `session_stats.json`, `version_table.csv`. |
| `stats.tex` | Macros `\nHuman`, `\nTurns`, `\nTools`, `\nEntries`, `\nHarness`, `\nShell` read by `main.tex`; regenerated by `make_figures.py`. |
| `main.pdf` | Compiled paper. |

## Build

```bash
cd paper/agentic_research
../../.venv_sbel/bin/python make_figures.py                                  # figures + stats.tex
cmd.exe /c "latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex"   # Windows TeX from WSL
```

## Provenance of the numbers

* Repository counts (Table 2) were taken from the working tree on 2026-09-21; the session
  counts come from the transcript of the final session (2026-09-17 to 21). The transcript keeps
  growing while that session is open, so `\nTurns`/`\nTools` move; `\nHuman` counts only messages
  typed by the human (harness-generated user-role entries such as task notifications, command
  echoes, compaction summaries and image attachments are excluded, and typed shell commands are
  counted separately as `\nShell`).
* The classification of the human messages in Appendix C was done by hand on the 36 messages
  present on 2026-09-21; re-check it if `\nHuman` changes.
* The incident list (Table 1) is reconstructed from the transcript and the ledger records of the
  final phase; it is complete for that phase only.
