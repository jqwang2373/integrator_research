# paper

The manuscript and nothing else. Proofs are in `../proof/`, code and results in `../numerics/`, the
historical evidence ledger in `../validation/`.

| File / folder | What it is |
| --- | --- |
| `main_cmame.tex` | **The manuscript** (CMAME, `elsarticle`), rewritten 2026-09-21. Generated by `rewrite/assemble.py` from the section files in `rewrite/parts/`; edit the parts, not this file. |
| `main_cmame.pdf`, `main_cmame.log` | Compiled PDF and LaTeX log (`validate_manuscript.py` reads the log). |
| `rewrite/parts/*.tex` | The manuscript, one file per section, concatenated in lexical order. |
| `rewrite/assemble.py` | Concatenates the parts into `main_cmame.tex` (or `main_rewrite.tex` for a draft) and copies the experiment figures from `../numerics/v049_paper_experiments/results/` into `figures/`. |
| `rewrite/make_schematics.py` | Draws the schematic figures (`method_overview.png`, `chain_schematic.png`, `mechanisms.png`). |
| `rewrite/build_derived.py` | Writes the Elsevier flat copy (`cmame_submission_flat/`, `.zip`) and the arXiv preprint (`arxiv/`) from `main_cmame.tex`. Never edit those by hand. |
| `rewrite/OUTLINE.md`, `rewrite/EXPERIMENT_PLAN.md` | The rewrite plan and the execution record of the experiments E1–E7. |
| `figures/` | Figures referenced as `\figpath/<name>.png`: `e1_…`–`e6_…` (data, drawn by `../numerics/v049_paper_experiments/make_figures.py`) and the three schematics. |
| `highlights_cmame.txt`, `declarations_cmame.md`, `COVER_LETTER.md` | Journal sidecars. |
| `agentic_research/` | The process paper (ACL/NAACL two-column template): how the program was carried out by the coding agent, the incidents, the session statistics. Own `README.md`; figures and `stats.tex` from `agentic_research/make_figures.py`. |
| `slides/` | Talks and the autoresearch-methodology write-up (separate documents). |

The pre-rewrite manuscript package (2026-09-19 draft, its flat and arXiv copies, figures and
sidecars) is frozen at `../validation/legacy_drafts/main_cmame_pre_rewrite/`, where the evidence
ledger of `../validation/paper_v047_cylindrical_chain/` still validates it.

## Build

```bash
cd paper
python3 rewrite/assemble.py --target main_cmame            # parts -> main_cmame.tex, sync figures
cmd.exe /c "latexmk -pdf -interaction=nonstopmode -halt-on-error main_cmame.tex"   # Windows TeX from WSL
python3 rewrite/build_derived.py                            # flat copy + arXiv version
(cd arxiv && cmd.exe /c "latexmk -pdf -interaction=nonstopmode main_arxiv.tex")
../.venv_sbel/bin/python ../validation/validate_manuscript.py   # log clean, table numbers = result files, Lean names, arXiv sync
```

Figures: rerun `../numerics/v049_paper_experiments/make_figures.py` after any experiment changes
(it only reads the result JSON files), then `assemble.py`.
